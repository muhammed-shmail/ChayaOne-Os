# Install the Main PC hub

Full guide: [../INSTALLATION_GUIDE.md](../INSTALLATION_GUIDE.md).

1. Build the installer: run `BUILD-MAIN-PC-INSTALLER.bat` (output in `release-main-pc/`).
2. Run the installer on the cafe PC.
3. Start with `START-MAIN-PC.bat` (or the desktop shortcut).
4. Open `http://localhost:3000/setup` on the PC and complete the setup wizard.
